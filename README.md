# 🥗 Friend Meal Planner

Built for the **Hacktoberfest Weekend Challenge: Build for a Friend** (DEV `#hf26challenge`).

My roommate Nagaraj needed help eating high-protein vegetarian food on a ₹2000/week
budget — while strictly avoiding peanuts and lactose. So I built him a meal planner
that runs **entirely on his laptop**: no accounts, no API keys, no cloud, no data
ever leaving the machine.

## How it works

- Web UI (vanilla HTML/JS) + zero-dependency Python server (`app.py`, stdlib only)
- Meal plans are generated by **open-weight Gemma 3 1B** running locally via
  [Ollama](https://ollama.com) — the open model is what makes the whole thing work
- A **deterministic allergy guardrail** scans every plan line-by-line for allergen
  keywords (the small local model can slip — e.g. suggesting paneer to a
  lactose-allergic person) and appends an ⚠️ Allergy Check section flagging risky
  dishes for review

## Why open matters here

1. **Health data stays home.** Allergies and eating habits are sensitive — with a
   local open-weight model, none of it touches a server anyone else controls.
2. **Works offline.** Hostel Wi-Fi dies constantly; the planner doesn't care.
3. **Free forever.** No per-token billing for a student budget.
4. **Swappable.** Gemma 3 1B today (`OLLAMA_MODEL=gemma2:2b` tomorrow) — no vendor lock-in.

## Run it

```bash
# 1. Install Ollama: https://ollama.com
ollama pull gemma3:1b

# 2. Start the app (no pip install needed — stdlib only)
python3 app.py
# Serving on http://localhost:8000

# 3. Open http://localhost:8000, fill in your friend's profile, hit Generate
```

Env overrides: `PORT`, `OLLAMA_HOST`, `OLLAMA_MODEL`, `OLLAMA_NUM_GPU`
(default `0` = CPU inference, most portable; unset it on machines with a healthy GPU).

## Demo

Fill in: name `Nagaraj`, diet `Vegetarian`, allergies `peanuts, lactose`,
budget `₹2000` → a 7-day plan streams in (~40s on CPU), ending with the
⚠️ Allergy Check section.
